## 这是什么

一条**本地运行、可断网**的全自动短视频（营销号）生产线：

```
热点/反馈/persona → 选题(方向 5–8 → 选题 20+) → 写稿 → 双通道审稿 → 改稿(≤2轮) → 人工确认闸(仅B级)
   → CosyVoice 熊大熊二按句配音 → voice_master.wav
   → FFmpeg 单遍合成(跑酷循环裁长 → 缩放铺满 → 固定水印 → 混音 → 一次编码) → final.mp4
   → 定时/即时多平台发布 → 数据回收 → 报告与决策闭环 → 记忆沉淀
```

- **全流程无人值守**：唯一人工节点是「确认闸」，且**仅 B 级稿件需要人工**（A 级自动放行）。
- **按句可续传**：任意时刻断电/杀进程，重启后从第一个未完成的句子继续（已完成句**引擎调用次数为 0**）。
- **跑酷素材随机防搬运**：素材随机 + 入点随机 + 微变换 + 编码抖动，配相似度审计门禁。
- **不做音画同步**（口述 D2）：跑酷只是背景板，成片时长 = 人声实测时长，视频循环补齐即可。
- **本地优先**：无 Redis / 无 Docker / 无外部 DB；LLM 支持云端 + 本地兜底双通道。

## 五条不可动摇的原则

| 原则 | 工程强制手段 |
| --- | --- |
| **P1 本地优先** | 零外部服务；全链路可断网；模型权重与媒资落 `D:` 盘；每个外部依赖都有降级路径 |
| **P2 按句可续传** | 续传粒度 = 句子（场景级属二期）；产物路径由内容哈希决定；任何时刻杀进程均可恢复 |
| **P3 随机防搬运** | 随机化在编译前决策、种子化、落盘可复现；素材受「近 K 任务不重复」约束；相似度审计门禁（**与是否做音画同步无关**） |
| **P4 无人工介入** | 唯一人工节点 = 确认闸（仅 B 级）；其他环节禁止设计人工步骤；失败必须自动重试或降级 |
| **P5 确定可审计** | 同输入 + 同 seed ⇒ 同产物；模板 / 提示词 / 引擎版本 / 随机种子 / 滤镜图 / 人工操作全部留痕 |

## 怎么打开图形界面

```powershell
.\启动.bat                 # doctor 门禁 → 拉起服务 → 打开浏览器
# 手动起也行：uv run studio serve   ⇒ 浏览器打开 http://127.0.0.1:8787/
```

**界面由 API 进程直接托管**（`web/dist` 挂在 `/`），不需要另起静态服务器，也不需要
开 Vite 开发服务器 —— 后者只在改前端源码时用（`cd web && npm run dev`，5173 端口，
把 `/api` 与 `/ws` 代理到 8787）。改了前端源码要跑 `cd web && npm run build`，
API 才会看到新的产物。

**从零到第一支片子**（面板上四步，全在「渲染」面板）：

1. 左边栏点「渲染」；
2. 任务号已经填好（`ui-<日期>-<时刻>`），要接库里某版稿就改成那个任务号、文案留空；
   要直接出片就往「口播文案」里粘一段；
3. 画布档默认 `douyin_1080x1920_30fps_v1`，音色默认本机第一个 SAPI 音色；
4. 点「出片」。进度每 1 秒自己刷，跑完下面「成片」里就能直接播放。

> 四屏之间**不用手抄任务号**（T4.14）：选题卡「去稿件 →」、稿件详情行尾「去配音 →」/「去渲染 →」、
> 配音面板「去渲染 →」、渲染面板「去配音 →」—— 任务号由面板带过去。

命令行等价物：`uv run studio render make --task-id <任务号> --text "<文案>"`。
